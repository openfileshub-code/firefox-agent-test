# Каталог runtime-логов

Сюда пишутся ВСЕ логи проекта (корневая директория не засоряется):

- `browserd.log` — лог демона браузера (Playwright/Camoufox).
- `mcp_debug.log` — лог MCP-сервера (ротация до 5 МБ, 3 копии).
- `daemon_control.log` — лог скриптов управления демоном.
- `tool_audit.jsonl` — аудит каждого tool call и решений PolicyGuard.
- `pytest_run.log` — вывод последнего прогона тестов.

Содержимое каталога игнорируется git (см. `.gitignore`); в репозитории
хранится только этот README.
